# data/nrd — Nordum

Nordum is the constructed pan-Scandinavian written language
(<https://www.nordum.org>); upstream LanguageTool has no module. Module:
`crates/lt/src/nrd.rs` + `crates/lt/src/nrd/`; tests:
`crates/lt/tests/nordum.rs`; the owner-approved rule list is the
`new-languages/nordum/proposed-rules.md` sign-off package (outside this repo
until the staging folder is retired).

The **authoritative language source** is the owner's Nordum repository
(<https://github.com/nordum/nordum>): the specification,
the word list generator and the site dictionary live there. Language changes
(`-en` vs `-an`, irregular verbs, compound rules, …) are made there first,
then this directory is regenerated.

### Provenance of `nrd.dic` (derived data)

`nrd.dic` is generated by `tools/nordum-dict/build-nordum-dict.py`. The
generator reads **only the word lists** of the source dictionaries (it skips
the count line, strips affix flags and comments and ignores every `.aff` rule);
the source `.aff` files are *not* incorporated into the generated dictionary.
`nrd.aff` is hand-authored (only `SET UTF-8`), so no third-party affix rules
are redistributed with Nordum.

| Source folded into `nrd.dic` | What is taken | License |
|---|---|---|
| Authoritative Nordum word list + accepted alternatives (`nordum` repository) | words | CC BY 4.0 OR LGPL-2.1-or-later (owner dual license) |
| `words/core_additions.txt` | hand-authored words | LGPL-2.1-or-later |
| `nb_NO.dic` (LibreOffice dictionaries `no/`) | word list only | CC BY 4.0 (Nasjonalbiblioteket/Ordbanken) + CLARIN PUB+BY (nyordslister 2018–2024, CLARINO Bergen; attribution) |
| `da_DK.dic` (Stavekontrolden) | word list only | GPL-2.0 OR LGPL-2.1 OR MPL-1.1 (tri-licensed) |
| `sv_SE.dic` (Göran Andersson) | word list only | LGPL-3.0 |

`nrd_core.dic` (the suggestion candidate list) contains only the Nordum word
list, its accepted alternatives and `words/core_additions.txt`; no
source-dictionary words are folded into it.

Modifications applied by the generator (recorded here as the attribution
condition of CC BY 4.0 requires): every source word is passed through the
Nordum orthographic transformations (`ck`→`kk`, `ks`→`x` incl. number words,
`ph`→`f`, `skj`→`sk`, `ld`→`ll`, `hv-` question words drop the `h`, `c`→`s`
before `e/i/y` else `k`), the diphthongs are normalized (`ej`/`aj`→`ei`,
`øj`/`øy`→`øi`), and both the primary (`æ`/`ø`) and accepted secondary
(`ä`/`ö`) vowel spellings are kept. The result is merged with the Nordum word
list and additions, deduplicated and sorted before writing. No source-language
morphology (affix rules) is carried over. Legal review of distributing this
derived dataset is a pending owner item (D14); the generated files ship with
these notices in `THIRD_PARTY_NOTICES.md`.

## Modifying this language

No tagger and no POS dictionary: rules work on the surface token stream
(`postag="SENT_START"` is available).

### Rule kinds

1. **XML pattern rules** — `rules/grammar.xml`, same capabilities as the other
   hand-authored languages (markers, antipatterns, `<match no>` reordering and
   case conversion, `<regexp>` sentence rules with numbered capture groups —
   see `NDM_YN_QUESTION`). Keep rule ids stable.
2. **List rules** — `rules/*.txt` + a `SimpleReplaceRule` entry in
   `crates/lt/src/nrd/rules.rs`. `check_case.txt` lists the correct lowercase
   forms (this is where `nordum` itself is enforced).
3. **Speller word lists** — `hunspell/ignore.txt` for words the generated
   dictionary misses (e.g. `barnhage`, `España`), `repetition_exceptions.txt`
   for legitimate repetitions.
4. **Rust built-ins** — `crates/lt/src/nrd/context.rs`
   (`NDM_PRON_POSS`: possessive agreement from the inferred noun gender;
   `NDM_COMPOUND_LEX`: dictionary-driven split compounds, **default-off**
   with guards) and the shared `WordRepetitionRule`
   (`NDM_WORD_REPETITION`), both wired in `crates/lt/src/pipeline.rs`.

### Overlap priorities

`crates/lt/src/nrd/priorities.rs`: the speller is `-1000`, style rules `-50`,
the rest `0`; ties are resolved by match length and then order. Curated list
rules intentionally beat the speller for the same range.

### Adding a rule: checklist

1. Change the Nordum source (spec / dictionary generator) first when the rule
   is about the language standard, then mirror it here.
2. Add the rule/file and `<example>` cases; extend
   `nordum_rules_fire` / `nordum_correct_sentences` in
   `crates/lt/tests/nordum.rs`; update `active_rule_count()` in
   `nordum_engine_state` (currently 22) for default-on XML rules.
3. Register changed data (see below), run the tests and clippy.

### Notes / gotchas

- Rule suggestions come from the **core** dictionary (`nrd_core.dic`), not the
  1.1M-entry generated dictionary; put useful suggestion targets in
  `words/core_additions.txt`.
- The generated dictionary is a *whitelist*: it accepts transformed
  Norwegian/Danish/Swedish forms, so the intentional normalizations are done by
  the rules, not by spelling errors. Over-acceptance is acceptable, a false
  positive on a valid Nordum form is not — add missing valid words to
  `ignore.txt` or `core_additions.txt`.
- Owner decisions currently encoded (see internal development notes D-155):
  `forskell` (D5), no K/J/G rules (D6), definite singular `-en` (D7),
  irregulars `er/har/går` (D8), compounds keep doublings (D9),
  `nordum` lowercase, endonym preference; the `ks` → `x` rule also applies to
  number words (`seks` → `sex`, `seksten` → `sexten`, `seksti` → `sexti`) and
  `mykket`/`meget` are accepted spellings of `mye` (owner 2026-09-20).
- The upstream Nordum generator no longer emits `gåer`/`gåede`/`gået` or
  `haver`/`havede` (`nordum/nordum@6be2b42`); keep the two sides in sync when
  the word list changes.

## Regenerating

```sh
python3 tools/nordum-dict/build-nordum-dict.py \
    --nordum-wordlist /path/to/nordum/build/assets/data/wordlist.txt \
    --nordum-dictionary /path/to/nordum/build/assets/data/dictionary.json \
    --additions data/nrd/words/core_additions.txt \
    --sources nb_NO.dic da_DK.dic sv_SE.dic \
    --out data/nrd/hunspell/nrd.dic \
    --out-core data/nrd/hunspell/nrd_core.dic \
    --report data/nrd/hunspell/build-report.txt
python3 tools/lt-sync/lt_sync.py add-local generated data/nrd/hunspell/nrd.dic \
    data/nrd/hunspell/nrd_core.dic data/nrd/hunspell/build-report.txt \
    --generator tools/nordum-dict/build-nordum-dict.py
cargo test -p lt-data
```

## Registering data changes

```sh
python3 tools/lt-sync/lt_sync.py add-local hand-authored <changed files> \
    --license "LGPL-2.1-or-later" --license-source "LICENSE"
cargo test -p lt-data
```

Tests: `cargo test -p lt --test nordum`.
