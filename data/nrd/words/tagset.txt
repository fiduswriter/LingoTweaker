# Nordum tagset (data/nrd/words/tagset.txt)

This is the description of the tags used by the Nordum tagger.

---
The Nordum tagger dictionary is generated by
`tools/nordum-dict/build-nordum-tagger.py` from three sources:

1. the authoritative Nordum word list (`dictionary.json` + `wordlist.txt`
   from the Nordum project) — POS, gender and inflections per entry, forms
   generated per NORDUM_LANGUAGE_SPECIFICATION.md §4;
2. the Danish Stavekontrolden tagger dictionary (`danish.dict`), converted
   with the Nordum orthographic rules and mapped to the Nordum tagset;
3. the Swedish tagger dictionary (`swedish.dict`), converted the same way.

The tagset follows the Stavekontrolden style: 3-letter part-of-speech codes
with colon-separated feature suffixes (Nordum keeps only the features that
are reliable after the conversion — gender and number; the Danish case and
definiteness features are dropped because the simplified Nordum gender
system, spec §4.3.3, does not preserve them). Swedish SUC-style tags are
mapped onto the same codes.

The engine tags words by returning one string per reading, for example:

 arbeider	arbeide	ver:præ
 jentar	jente	sub:ube:plu:com:nom

Rules match with postag regular expressions, e.g. all verbs:

 <token postag_regexp="yes" postag="ver:.*" />

or plural nouns (spec §4.3.1: plurals always end in -ar):

 <token postag_regexp="yes" postag="sub:.*:plu:.*" />

Part-of-speech tags:

ver	verbum (verb); features: inf (infinitive), præ (present, always -er),
	dat (past), imp (imperative), kor (supine/perfect participle -et),
	lan (present participle -ende)
sub	substantiv (noun); features:
	ube/bes (indefinite/definite),
	sin/plu (singular/plural),
	com/neu (common/neuter gender, spec §4.3.3)
adj	adjektiv (adjective); features:
	pos (positive), kom (comparative -ere, spec §4.4.1),
	sup (superlative -est)
pron	pronomen (personal/reflexive pronouns, spec §4.6)
det	determiner (possessives min/mitt/mina..., articles, spec §4.6)
adv	adverb
prep	praepositio (preposition, spec §3.3.4)
kon	konjunktion (conjunction; distinguishes att/å, spec §4.2.4)
int	interjektion
num	numeral (spec §2.4)
pro	proprium (proper name / geographic endonym, spec §5.6)
inf	infinitive marker (å, spec §4.2.4)

Feature values:

ube	ubestemt	indefinite
bes	bestemt	definite
sin	singularis	 singular
plu	pluralis	plural
com	common (en-words, spec §4.3.3)
neu	neutrum (ett-words, spec §4.3.3)
pos	positiv	1st degree
kom	komparativ	2nd degree
sup	superlativ	3rd degree
nom	nominativ	subject/object form (pronouns)
inf	infinitiv
præ	præsens
dat	præteritum
imp	imperativ
kor	perfektum participium (supine)
lan	præsens participium
